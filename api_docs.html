Introduction

Welcome to the Invoice Management API documentation. This RESTful API allows you to create, read, update, and delete invoices programmatically.

Base URL

http://your-domain.com/api/index.php

Key Features

  • ✅ JWT-based authentication
  • ✅ Full CRUD operations on invoices
  • ✅ Automatic calculations (subtotal, tax, total)
  • ✅ PDF generation
  • ✅ Pagination support

Authentication

The API uses JWT (JSON Web Tokens) for authentication. Include the token in the Authorization header for all protected endpoints.

Login

POST /auth/login

Request Body

Parameter Type Required Description
email string Required User email
password string Required User password
cURL
JavaScript
PHP
curl -X POST http://your-domain.com/api/index.php/auth/login \
  -H "Content-Type: application/json" \
  -d '{
    "email": "user@example.com",
    "password": "your_password"
  }'
fetch('http://your-domain.com/api/index.php/auth/login', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    email: 'user@example.com',
    password: 'your_password'
  })
})
.then(res => res.json())
.then(data => console.log(data.token));
$ch = curl_init('http://your-domain.com/api/index.php/auth/login');
curl_setopt($ch, CURLOPT_POST, true);
curl_setopt($ch, CURLOPT_POSTFIELDS, json_encode([
    'email' => 'user@example.com',
    'password' => 'your_password'
]));
curl_setopt($ch, CURLOPT_HTTPHEADER, ['Content-Type: application/json']);
curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);
$response = curl_exec($ch);
$data = json_decode($response, true);
echo $data['token'];

Response

{
  "status": "success",
  "token": "eyJ0eXAiOiJKV1QiLCJhbGc..."
}
💡 Using the Token: Include the token in subsequent requests: Authorization: Bearer YOUR_TOKEN

API Endpoints

List Invoices

GET /invoices

Query Parameters

Parameter Type Default Description
page integer 1 Page number
limit integer 10 Items per page
cURL
JavaScript
curl -X GET "http://your-domain.com/api/index.php/invoices?page=1&limit=10" \
  -H "Authorization: Bearer YOUR_TOKEN"
fetch('http://your-domain.com/api/index.php/invoices?page=1&limit=10', {
  headers: { 'Authorization': 'Bearer YOUR_TOKEN' }
})
.then(res => res.json())
.then(data => console.log(data));

Create Invoice

POST /invoices

Request Body

Field Type Required Description
invoice_number string Required Unique invoice number
invoice_date date Optional Invoice date (YYYY-MM-DD)
due_date date Optional Due date
bill_to string Optional Customer name
ship_to string Optional Shipping address
items array Required Invoice line items
tax number Optional Tax percentage
discount number Optional Discount amount
shipping number Optional Shipping cost

JavaScript
curl -X POST http://your-domain.com/api/index.php/invoices \

    "discount": 0,
    "shipping": 10

  method: 'POST',
  headers: {
    'Authorization': 'Bearer YOUR_TOKEN',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    invoice_number: 'INV-001',
    bill_to: 'John Doe',
    items: [
      {description: 'Product A', quantity: 2, rate: 100}
    ],
    tax: 10,
    discount: 0,
    shipping: 10
  })
})
.then(res => res.json())
.then(data => console.log(data));

Error Handling

HTTP Status Codes

Code Description
200 Success
400 Bad Request - Invalid parameters
401 Unauthorized - Invalid or missing token
404 Not Found - Resource doesn't exist
500 Internal Server Error

Error Response Format

{
  "status": "error",
  "message": "Description of the error"
}
⚠️ Common Errors:
  • 401 Unauthorized: Check your token is valid and included in headers
  • 400 Bad Request: Verify all required fields are provided
  • 404 Not Found: Ensure the invoice ID exists

Complete Examples

Full Workflow Example

Here's a complete example showing how to authenticate and create an invoice:

JavaScript
PHP
// Step 1: Login
const loginResponse = await fetch('http://your-domain.com/api/index.php/auth/login', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    email: 'user@example.com',
    password: 'password'
  })
});
const { token } = await loginResponse.json();

// Step 2: Create Invoice
const invoiceResponse = await fetch('http://your-domain.com/api/index.php/invoices', {
  method: 'POST',
  headers: {
    'Authorization': `Bearer ${token}`,
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    invoice_number: 'INV-001',
    bill_to: 'John Doe',
    items: [
      { description: 'Web Development', quantity: 1, rate: 1000 }
    ],
    tax: 10
  })
});
const invoice = await invoiceResponse.json();
console.log('Invoice created:', invoice);
<?php
// Step 1: Login
$ch = curl_init('http://your-domain.com/api/index.php/auth/login');
curl_setopt($ch, CURLOPT_POST, true);
curl_setopt($ch, CURLOPT_POSTFIELDS, json_encode([
    'email' => 'user@example.com',
    'password' => 'password'
]));
curl_setopt($ch, CURLOPT_HTTPHEADER, ['Content-Type: application/json']);
curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);
$response = curl_exec($ch);
$data = json_decode($response, true);
$token = $data['token'];

// Step 2: Create Invoice
$ch = curl_init('http://your-domain.com/api/index.php/invoices');
curl_setopt($ch, CURLOPT_POST, true);
curl_setopt($ch, CURLOPT_POSTFIELDS, json_encode([
    'invoice_number' => 'INV-001',
    'bill_to' => 'John Doe',
    'items' => [
        ['description' => 'Web Development', 'quantity' => 1, 'rate' => 1000]
    ],
    'tax' => 10
]));
curl_setopt($ch, CURLOPT_HTTPHEADER, [
    'Content-Type: application/json',
    'Authorization: Bearer ' . $token
]);
curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);
$response = curl_exec($ch);
echo $response;
